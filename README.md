# REVERBERATE — Girls Band Cry 全角色档案与灵魂设定集

> **REVERBERATE** = **R**ock **E**choes **V**oice, **E**motion **R**eturns — **B**urning **E**very **R**ebel, **A** **T**race **E**ndures
> *以「回响」命名：呐喊撞上墙壁再折返的那一下，才是它真正被听见的时刻。*

**REVERBERATE** 是一个面向 **AI 角色扮演、桌宠交互（Desktop Pet）与 Agent 人格构建** 的结构化角色设定知识库，收录了 **《Girls Band Cry（ガールズバンドクライ）》** 企划 **五大乐队共 24 位角色** 的深度分析档案与灵魂核心设定（总计 **48 份 Markdown 文档**）。

每位角色均采用**「事实记忆 + 灵魂核心」双文件结构**：一份用于系统化沉淀客观经历、人际网络与 `IF-THEN` 行为规则，另一份则将其高密度提炼为可直接注入系统提示词（System Prompt）的性格内核与对话写作指南。

---

## ✨ 命名巧思（Why "REVERBERATE"?）

- **物理层面的「回响」**：本作的核心不是「努力就有回报」的偶像叙事，而是**五个人把无处可去的愤怒砸进音箱，让它撞上 live house 的墙壁再折返回来**。`Reverberate` 精确指向那个折返——声音不是被听见才存在，是被反弹才成立。
- **叙事层面的「回响」**：桃香退出ダイヤモンドダスト留下的伤口，在トゲナシトゲアリ身上回响；日菜与仁菜的旧账，在舞台上回响；甚至连「不登校」「被父母放弃」「失去家人」这些各自的断点，都在同一段副歌里互相回响。本库正是要把这些**跨角色的回声关系**固定下来。
- **首字母彩蛋**：`R`ock `E`choes `V`oice — `V` 取自 **Voice**，也暗合本作标题里的 **Cry**（呐喊）。全名读快了，就是「让歌声继续响下去」。

## 🧩 双文件设计规范

每个角色目录均包含两份互补的 Markdown 文档，全库 24 位角色严格保持一致的骨架结构。

### 1. `A_<角色名>.md` — 角色深度分析档案
- **定位**：全量事实记忆库与精细行为规范手册（单篇约 1.2 万～2.2 万字节）。
- **适用场景**：RAG 检索增强、长上下文设定查阅、精细化剧情推演与人际称呼校验。
- **固定结构**：
  - **基础样貌与身高**：身高、发色瞳色、视觉印象、未公开/区分项说明、生日/星座、血型、官方代表色（含 HEX 参考）。
  - **PART A：角色记忆 —— 客观事实与经历**
    - `基本身份`（姓名/原名/罗马音、所属与年级、乐队与小分队、职责、喜恶特技、CV 等结构化表格）
    - `人生关键事件时间线`（按前史、TV 各期主线、手游剧情推进整理）
    - `重要关系`（关系性质、双向称呼方式、核心互动动态）
    - `核心信念与价值观`
    - `习惯与日常`
  - **PART B：角色人格 —— 行为模式与表达风格**
    - `Layer 1：身份锚点`（自我认知 & 他人眼中的她）
    - `Layer 2：表达风格（CRITICAL）`（语气基调、典型口头禅与中日台词对照、称呼方式对照表、语境声调变化）
    - `Layer 3：情感与决策模式`（情绪表达、决策风格、冲突应对、压力应对机制）
    - `Layer 4：行为规则`（身体习惯与小动作、社交互动默认反应及 `IF ... THEN ...` 规则集）
    - `核心矛盾与成长轨迹`
    - `代表台词精选`
    - `关键物品与意象`

### 2. `soul.md` — 角色灵魂核心
- **定位**：高密度人格灵魂摘要（单篇约 5 千～8 千字节）。
- **适用场景**：直接作为 AI Agent / 桌面宠物（桌宠）的核心人格提示词（System Prompt / `SOUL.md`），在精简上下文开销的同时稳定保持角色灵魂、语癖与情绪张力。
- **固定结构（24 份文件全统一）**：
  1. **核心驱动力**
  2. **价值观与信念**
  3. **情感核心**
  4. **内在矛盾**
  5. **成长弧线**
  6. **她在团队里的位置**（内含 **`桌宠写作要点`**：默认语癖、反差/情绪触发开关、固定称呼、核心互动氛围）
  7. **一句话灵魂总结**

## 🎸 五支乐队速览

### トゲナシトゲアリ（刺无刺有 / Togenashi Togeari）
> 由「新川崎（仮）」（仁菜・桃香・昴）与 VOCALOID 双人组合「beni-shouga」（智・露帕）在第 6 话合流而成。第 7 话在 live house 上，尚未定名的仁菜看见观众 T 恤上的「トゲアリトゲナシトゲトゲ」，当场即兴命名。简称「トゲトゲ」。
>
> **全员共同点：都是主动或被动「脱离既有轨道」的人——辍学、离家、失去家人、放弃安稳。作品的命题不是「努力就会成功」，而是「就算不成功，也要把话说出来」。**

### ダイヤモンドダスト（钻石星尘 / Diamond Dust）
> 桃香作为吉他主唱曾所属的乐队。原为高中轻音部 4 人组，indies 期已具人气；major 出道前夕被要求转为偶像乐队路线，桃香拒绝并退出。此后仁菜的旧同学日菜通过甄选成为二代主唱。
>
> **与トゲトゲ的关系：不是敌人，是「逃走的人」与「留下来的人」互相推背的宿敌。** 第 8 话后，两边成了「彼此见证对方没有后悔」的存在。

### Canna Lily
> 手游《First Riff》原创。**「『がむしゃら』な足跡から咲くロックンロールバンド」**——从「不顾一切」的脚印里开出的摇滚乐队。纵使被令人心碎的命运摆布，也具备不肯死心、硬要迈出下一步的气概。那些不成样子的花瓣泥泞地拨响的冲动，终将成为鲜艳的花。

### F-272
> 手游《First Riff》原创。**「みんなのこと、大っ嫌い。」**——一群神经紧绷、被淘汰下来的偶像志愿生。希望与绝望早已褪色，日子在冷笑与推责中流逝。本该无痛的心，却忽然开始发出嘎吱声。
>
> **全员共同创伤：都当过「偶像志愿生」，都在甄选里被刷下来过。**

### クズミミズク（渣味噌 / Kuzumi Mizuku）
> 手游《First Riff》原创。**「だらしない大人4人と意識の高い毒舌なガキ1人からなる青春パンクバンド」**——为了工作而组建、临时凑数的凑人头。逼近的大人内情与突如其来的规格变更。既不酷又丢人，没有热情、没有精神、也没有实力。**就算这样，也还是可以做音乐的。**

## 🚀 使用建议

- **桌面宠物 / 轻量对话 Agent**：直接加载目标角色目录下的 `soul.md` 作为基础人格设定，可立即获得第一人称、典型语癖、队友称呼及常见触发反应。
- **高还原深度扮演 / 多角色剧场**：以 `soul.md` 作为核心 System Prompt 锚定性格底色，并将 `A_<角色名>.md` 接入知识库（或按需抽取 `PART A 重要关系`、`PART B Layer 2 表达风格` 与 `Layer 4 行为规则`），防止时间线与称呼细节「串线」。
- **多时间线防混淆**：若需限定特定时期（如 TV 第 1–7 话「新川崎（仮）」时期、第 8 话后トゲトゲ与ダイダス的宿敌关系、剧场版《THE MOVIE》之后），请留意 `A_<角色名>.md` 中的**时间线阶段划分**与**未公开/区分项说明**。
- **跨队对照阅读**：本库刻意保留了「同一事件的多视角版本」——例如第 8 话 live house 后台的送别，在桃香、奈奈、凛、爱四份档案里各有解释。想推导某一方的心理动因时，对照阅读比单读一份更准。

## 📌 与《Love Live!》系角色库的关键区别

本库在结构上与同源的 Love Live! 角色库（IDYLL）保持同构，便于交叉使用；但在**人格底色**上有意做了区分：

| 维度 | Love Live! 系 | Girls Band Cry 系 |
|---|---|---|
| 情绪基调 | 明亮、向前、治愈 | 低沉、带刺、不平 |
| 语癖特征 | `〜だよ！` 式元气腔、`〜ちゃん` 式亲昵称呼 | 短句、断句、口头脏话边缘、敬语施压 |
| 冲突处理 | 通过对话与羁绊化解 | 先撞上去、伤人、再各自消化 |
| 核心命题 | 「一起实现梦想」 | 「就算不被认可，也要把话说完」 |
| 桌宠适配 | 陪伴感、撒娇互动 | 被顶撞、被追问、被推一把的紧张感 |

**因此：不要把 Love Live! 的语癖与称呼体系套用到本库角色身上。** 每位角色的 `soul.md` 第 6 段 `桌宠写作要点` 已明确给出该角色专属的默认语癖与固定称呼。
